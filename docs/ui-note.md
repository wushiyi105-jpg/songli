# UI 说明：送礼

- **谁在什么时刻打开**：给预算和时间都有限的人。
- **首屏任务句**：这份礼，怎么选不踩雷。
- **主操作**：按「记关系和预算 → 出三个候选 → 核对往年与到货」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：精品店选礼台；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：精品店选礼台。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给预算和时间都有限的人：先记关系、场合、避讳和最迟到手日，再给三个理由不同的候选。往年送过什么、会不会迟到，都能一票否决。
